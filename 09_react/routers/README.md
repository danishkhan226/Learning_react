# React Router Learning Project

A React and Vite project created to practice client-side routing with
React Router DOM.

## Features

- Home page routing
- About page routing
- Product page routing
- Nested product category routes
- Men, Women, and Kids category pages
- Courses page
- Dynamic course detail routing
- Custom 404 Not Found page
- Navigation with Link
- Programmatic navigation with useNavigate
- Dynamic URL parameters with useParams
- Nested route rendering with Outlet
- Shared Navbar and Footer layout

## Technologies

- React
- Vite
- React Router DOM
- JavaScript
- Tailwind CSS
