# Style with CSS

A simple React project to practice styling components using CSS and CSS modules.

## Overview

This project demonstrates how to:
- build a React app with reusable components
- style components using CSS modules
- keep component-specific styles scoped and organized
- create a small UI layout with a Header and Button

## Tech Stack

- React
- Vite
- CSS Modules
